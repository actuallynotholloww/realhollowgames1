## Save backups

The Settings page can download and restore a local backup of this site's localStorage, the active tab's sessionStorage, and same-origin IndexedDB. To move saves, download the JSON backup, then either select that file directly on the destination site or open it in a text editor, copy all its contents, paste them into the restore box, and choose **Restore Pasted Backup**. No account or server is required.

Browser security prevents this site from reading cookies, server-side game accounts, or saves stored by games on other websites. Those games need their own export/import feature to include their data.
